# MoodBot Website

Official website for MoodBot — Clash of Clans automation tool.

🌐 Live website: https://miichmood.github.io/MoodBot-Website/

Main project:
https://github.com/miichmood/MoodBot-ClashOfClans

The RC32 site includes the eight-language interactive manual and a browser preview of the Overview, Activity, and Recorder panels.

Run `npm ci` followed by `npm run dev` to open the site locally. Use `npm run typecheck` and `npm run build` before publishing with GitHub Pages.
